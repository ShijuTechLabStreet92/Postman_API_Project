# Postman API Testing

This repository contains my API testing practice using **Postman**. It demonstrates CRUD operations, environment variables, test scripts, and API validation.

## 🚀 Project Overview

This project covers:

- API Testing using Postman
- REST API CRUD Operations
- Test Script Validation
- Environment Variables
- Collection Variables
- JSON Request & Response Validation

## 📌 API Operations Covered

- ✅ POST – Create Booking
- ✅ GET – Retrieve Booking
- ✅ PUT – Update Booking
- ✅ DELETE – Delete Booking

## 🧪 Test Cases Covered

- Status Code Validation
- Response Time Validation
- Response Body Validation
- Header Validation
- JSON Schema Validation
- Token Generation Validation
- Environment Variable Validation
- Response Field Validation

## 🔧 Postman Features Used

- Environment Variables
- Collection Variables
- Assertions (`pm.test`)
- Dynamic Variables

## 🛠 Tools Used

- Postman
- Git
- GitHub

## 📂 Project Structure

```
Postman_API_Testing

```

## ▶️ How to Run

1. Import the Collection into Postman.
2. Import the Environment.
3. Select the QA Environment.
4. Execute requests in the following order:
   - Generate Token
   - Create Cordinates
   - Get Cordinates
   - Update Cordinates
   - Delete Cordinates
